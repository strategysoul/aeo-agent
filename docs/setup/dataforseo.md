# Connect DataForSEO

Last checked: 2026-10-17, against [DataForSEO's OAuth setup guide](https://dataforseo.com/help-center/connecting-the-remote-dataforseo-mcp-server-using-oauth), [Claude Code guide](https://dataforseo.com/help-center/3-ways-to-install-dataforseo-mcp-with-claude-code), [MCP server repo](https://github.com/dataforseo/mcp-server-typescript) and [pricing](https://dataforseo.com/pricing).

## What it adds

The same kind of data as Ahrefs or Semrush, paid per request instead of by subscription. You need only one of the three. DataForSEO suits small sites and occasional runs, because you pay only for what the agent uses.

| Step | What DataForSEO provides |
|---|---|
| Keyword discovery and scoring | search volume, keyword difficulty, intent, keyword suggestions and related keywords |
| Google results | live top 10 for a keyword, including AI Overview and "People also ask" |
| Competitor keywords | competitor domains and the keywords they rank for |

It does not give a site authority score, so difficulty is compared with an unknown authority and scored cautiously.

## Price

The agent reads your balance and DataForSEO's price list (both free) before each run, and spends at most 10% of the balance per site per run by default. Current prices: [dataforseo.com/pricing](https://dataforseo.com/pricing).

## Connect it

Your **API login and API password** are on the **API Access** page of your DataForSEO dashboard. The API password is generated by DataForSEO and is not your account password.

### Claude desktop and Cowork (no code, OAuth)

1. Open **Customize → Connectors**, click **+** and choose **Add custom connector**.
2. Name it `DataForSEO`, paste `https://mcp.dataforseo.com/mcp` as the URL and click **Add**.
3. On the connector page click **Connect**.
4. On the DataForSEO page click **Approve**, then return to Claude.
5. Set the tool permissions, then turn the connector on in the conversation where you run the AEO agent.

### Claude Code

Remote server, recommended:

```bash
claude mcp add --transport http dfs-mcp https://mcp.dataforseo.com/mcp
```

Then run `/mcp`, select `dfs-mcp` and authenticate. DataForSEO's own Claude Code guide also shows a version that sends your API login and password as an `Authorization: Basic` header instead of OAuth; follow that guide if OAuth does not work in your setup.

Local server, if you prefer to run it yourself (needs Node.js 18 or later):

```bash
claude mcp add dfs-mcp --env DATAFORSEO_USERNAME=<api_login> --env DATAFORSEO_PASSWORD=<api_password> -- npx -y dataforseo-mcp-server
```

On Windows, DataForSEO recommends adding the server to `%USERPROFILE%\.claude.json` with `"command": "cmd"` and `"args": ["/c", "npx", "-y", "dataforseo-mcp-server"]`; see their guide for the full entry.

### Without MCP

Set `DATAFORSEO_LOGIN` and `DATAFORSEO_PASSWORD` as environment variables. The agent then calls the DataForSEO API directly from the shell. Keep these out of chat and out of any shared folder.

## Check it worked

Run `/aeo-agent:aeo <your-domain> setup`. The DataForSEO row should show `available` and your balance in US dollars.

## Common errors

| What you see | Cause | Fix |
|---|---|---|
| 401 or authentication failed | wrong credentials, often the account password used instead of the API password | Copy the API login and password from **API Access** again. |
| Payment or balance errors | balance used up | Top up, or lower `budget.share_of_remaining`. The agent falls back to the next source. |
| Tools list shows only `docs_*` and `api_request` | expected for the current server | The agent calls endpoints through `api_request`. |
| Remote connection fails | DataForSEO's pages list more than one remote path (`/mcp`, `/v3/mcp`, `/http`) | Use the URL in DataForSEO's current guide for your client. |
| `npx` not found (local server) | Node.js missing | Install Node.js 18 or later, or use the remote server. |
